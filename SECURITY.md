# Security Policy

## Supported Versions

The default branch is the only actively maintained version of this static exercise.

## Reporting a Vulnerability

Do not publish sensitive details in a public issue. Use a private GitHub security advisory for this repository when available, or contact the maintainer through the [GitHub profile](https://github.com/raskirayhan). Include reproduction steps and avoid sending personal data.

The current project has no server, authentication, or secret configuration. Report unsafe markup, unexpected external requests, or asset-loading concerns privately.
