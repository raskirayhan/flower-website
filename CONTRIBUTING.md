# Contributing

Thanks for helping improve Flower Market.

## Workflow

- Read the README and inspect the related HTML or CSS before making a change.
- Keep changes focused and do not add generated files or unrelated redesigns to a pull request.
- Preserve the existing asset paths and check responsive behavior after layout changes.
- Update the README when a new section, asset, or interaction is added.

## Verification

Open `index.html` directly or run a local static server, then check the page at desktop and mobile widths. Confirm that local images, fonts, navigation, cards, and the newsletter section behave as intended.
